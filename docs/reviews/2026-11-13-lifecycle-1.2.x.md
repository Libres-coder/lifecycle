# Review - lifecycle 1.2.x (2026-11-13)

Independent adversarial review of the 1.2.x surface (`v1.2.0..HEAD`): statusline,
the context advice, hooks, threads, and their tests. Findings were reproduced
against the installed code in temporary directories; all are fixed in 1.2.4.

## Findings

**P1 - a wrong-typed field crashed the status line and the SessionStart hook.**
`used_percentage` was compared and formatted as a number without validation, so
`{"used_percentage": "85"}` (hand edit, merge) raised `TypeError` in
`statusline`, `status` and `resume --hook`. Fixed by sanitizing on read:
numeric strings are accepted, anything else is "unknown".

**P2 - `hook install` skipped the status line silently.** With another tool's
`statusLine` present it exited 0 having installed no reader, and the docs it
prints then said to install one. Fixed: it says the line was left alone and
names the command that owns it.

**P2 - legacy hook entries were never upgraded.** An entry from before `--hook`
existed matched the "already installed" test, so `resume --hook`'s token
recording never ran. Fixed: the exact legacy form is upgraded, and reported.

**P2 - `resume --hook` never records on `compact`.** The harness sends
`context_tokens` on `resume`/`fork`, not on `compact`; the docs said both. Fixed
the docs; the hook records what it is given.

**P2 - a stale percentage was given a fresh mtime.** `resume --hook` merged the
token count into the previous record, so yesterday's 94% looked live in a new
session. Fixed: the percentage is cleared; only the token count is recorded.

**P2 - `suggest` called a healthy reading "missing".** An empty hint (reading
below the nudge) took the "no reading" branch. Fixed: the branches are distinct.

**P2 - thread lookups did not normalize.** `create` lowercased the slug, lookups
did not, so `claim My-Thing` failed and its own advice then said the thread
exists. Reserved Windows device names (`nul`, `con`, ...) also passed validation
and failed at the first write. Fixed: one `normalize` used by every lookup; the
reserved names are refused.

**P2 - tests missed the boundaries.** `pct == warn`, `pct == nudge`,
`trigger <= 5`, and odd override strings were untested; the two silent-failure
paths above passed CI. Fixed: 89 -> 100 tests, including every boundary.

## Checked and found correct

`uninstall` preserves other tools' entries and removes only ours; `trigger()`'s
clamp keeps thresholds in 1..99; `_initialized` ignores an empty `.projtruth/`;
claim timestamps use one time basis for write and read.

## Not fixed, stated

- A reading belongs to a repository, not to a window. Two sessions on one repo
  overwrite each other's number; only the stale label separates them. Making
  readings session-keyed needs a session id the CLI does not reliably have.
