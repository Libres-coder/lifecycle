# Vision

## Problem

An AI agent declares a product "done" because the code compiles. Nobody can see
that the vision, the requirements, the design decisions, the evidence and the
release notes are missing - each one is somebody's job, and no single place says
which of them exist.

## Audience

A solo developer working with an agent, shipping a small product, who wants the
gaps named before a user finds them.

## Non-goals

- Not a project tracker: no tickets, no assignments, no estimates.
- Not a workflow engine: it does not run the work, it checks what the work left
  behind.
- Not a replacement for projtruth or corpus: it reads them.
